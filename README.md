### `CAMUNDA ARCHITECTURE RULE`

```text
DOMAIN LOGIC          → SERVICE
BUSINESS CAPABILITY   → SERVICE
PROCESS FLOW          → CAMUNDA
PROCESS STATE         → CAMUNDA
HUMAN APPROVAL        → BPMN USER TASK
TIME / RETRY          → BPMN
EXTERNAL SIGNAL       → MESSAGE / EVENT
FAILURE PATH          → BPMN ERROR / COMPENSATION
```

```yaml
camunda:
  bpm:
    - BPMN
    - gateways
    - events
    - timers
    - user tasks
    - subprocesses
    - call activities

  orchestration:
    - REST services
    - microservices
    - external systems
    - asynchronous processes
    - human workflows

  reliability:
    - retry strategies
    - process state
    - long-running workflows
    - failure paths
    - compensation concepts

  principle:
    - domain logic stays inside services
    - process flow remains visible
    - orchestration must reduce hidden coupling
```
